# Single-Bingo-Spree

In this console-based Java game, the goal is to have the least amount of tries, or rather, "cycles" when getting a BINGO. Do keep in mind however, this is purely by chance, so good luck!

(Note: Run this programs on a terminal (either from Windows Command Prompt or Windows Terminal), as some may not support ANSI, which would REALLY break the game entirely. Thank you for reading this)
